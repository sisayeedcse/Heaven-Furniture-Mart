# Heaven Furniture Mart — RacDox Hackathon Submission 🏆

![Heaven Furniture Mart](images/heaven%20furniture%20mart.png)

A premium, bespoke landing page built for **Heaven Furniture Mart**, a luxury furniture and interior styling company based in Chattogram, Bangladesh. 

This project was created as a submission for the **RacDox Hackathon** (September 2026).

## 🎯 Project Focus
This landing page was engineered specifically around the hackathon judging criteria:
- **70% UX & Conversion:** Mobile-first sticky CTAs, frictionless WhatsApp form integration, fluid typography, and immediate value proposition.
- **20% Visual Design:** A restrained luxury color system (Deep Teal & Ivory) derived from the original brand logo, with editorial asymmetric layouts.
- **10% Technical Execution:** Vanilla HTML5, CSS3, and JavaScript. Zero bloat, prefers-reduced-motion support, 100% accessible inputs, and instant loading times.

## 🛠️ Tech Stack
- HTML5 (Semantic & Accessible)
- CSS3 (Custom properties, fluid clamps, CSS Grid)
- Vanilla JavaScript (IntersectionObservers, mobile drawer, form handling)
